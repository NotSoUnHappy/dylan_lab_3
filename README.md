## temperature converter

## usage
this program converts one value into kelvin Celsius and Fahrenheit 

## how to use
1: open the program in visual studio
2: press ctrl+f5
3: provide what kind of temperature your first measurement is in, it accepts up to 30 characters but uses the first letter to determine what measurement to use 
4: input the actual measurement, it accepts positive negative decimals whole numbers and incorrect inputs default to 0

## sample input output
input: F 212
output: K: 373.15, C:100, F:212
